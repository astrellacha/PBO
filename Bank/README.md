## Class Overview

- **`Account`** — Menyimpan saldo, total deposit, total withdraw.

- **`Customer`** — Menyimpan nama depan/belakang & array rekening (maks 2).
  Method: `setaccount()`, `getAccount()`.
- **`Bank`** — Mengelola kumpulan nasabah dalam `ArrayList<Customer>`.
